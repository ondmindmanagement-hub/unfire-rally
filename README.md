# Unfire Rally · Tenis

Juega al tenis en la tele usando tu móvil como raqueta. Sin consola ni mandos especiales: abre el juego en el navegador de la pantalla grande, entra con el móvil y golpea.

- **Pantalla:** `/tv/` (Mac, PC o tele con navegador).
- **Mando:** `/controller/` en el móvil, con el código de 4 letras que muestra la tele.
- Hasta 4 jugadores (dobles). Sin móvil: teclado.

Los golpes se detectan con el giroscopio del móvil en el propio teléfono. Solo el emparejamiento pasa por un servidor de señalización de PeerJS; los movimientos viajan entre dispositivos por WebRTC. No se guardan datos personales.
